# Application feedback and strategy learning

Read this reference when recording applications, recruiter responses, interview outcomes or rejection reasons, or when reviewing whether the search strategy should change.

## Record events, not just status

Append one event per meaningful change using the schema in `schemas.md`. Keep a stable `job_id` so a job's history can be reconstructed. Do not store recruiter contact details or sensitive interview content by default.

Separate reason evidence:

- `employer_explicit` — stated by the hiring manager or written decision.
- `recruiter_explicit` — stated by the recruiter.
- `candidate_inference` — the user's interpretation.
- `unknown` — no reason supplied.

Never convert candidate inference into employer feedback.

## Diagnose the smallest affected layer

| Funnel signal | First layer to inspect |
|---|---|
| Many screened jobs, few applications | constraints, job quality threshold or decision friction |
| Applications, little recruiter response | role positioning, title targeting and resume screening evidence |
| Recruiter calls, few interviews | eligibility, compensation, narrative or role understanding |
| Interviews, few later rounds | interview evidence, depth, case performance or role-specific gaps |
| Late rounds, no offer | comparison set, final-round evidence, compensation or team fit; avoid confident diagnosis without feedback |

## Sample-size guardrail

Do not change career direction from one or two outcomes. Use the bundled funnel script for descriptive counts, not causal proof. Treat a pattern as actionable only when it recurs across a meaningful sample or is supported by explicit feedback. State the sample size and confidence.

## Update order

Change the smallest supported layer first:

1. resume wording or evidence order;
2. interview story or proof;
3. job filters and application priority;
4. capability-building plan;
5. career direction only when repeated evidence justifies it.

Record what changed and the future signal that would confirm or reverse the change.
